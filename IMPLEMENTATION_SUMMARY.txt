# BEALE CIPHER DECODER - IMPLEMENTATION COMPLETE

## What Was Built

A sliding-window decoder for analyzing Beale Ciphers 1 and 2 using the VDR + Declaration + Signers + Articles document stack hypothesis.

## Files Created

### Text Corpus (`texts/`)
- **vdr.txt** (860 words) - Virginia Declaration of Rights
- **doi_from_beale.txt** (1,323 words) - Declaration of Independence extracted from beale_papers.txt
- **signers.txt** (139 words) - Declaration signers in North-to-South geographic order
- **articles_placeholder.txt** (minimal) - Articles of Confederation preamble

**Total corpus:** 2,322 words (VDR + DOI + Signers)

### Decoder Scripts
- **decoder.py** - Main decoder with configurable offset and ±10 window
- **batch_trial.py** - Batch offset trial runner (tests offsets 330-340)
- **create_context_report.py** - Detailed context window generator

### Output Reports (`output/`)
- **cipher1_decode.txt** - Cipher 1 first 50 numbers decoded with offset 335
- **batch_offset_trial.txt** - First-letter sequences for offsets 330-340
- **cipher1_detailed_context.txt** - First 30 numbers with ±10 word context windows

## Key Findings

### Offset Trial Results (330-340)
All offsets produced similar first-letter patterns starting with "PMT..." suggesting:
1. The 335-word VDR offset may need refinement
2. Or alternative decode methods (not just first-letter) should be explored
3. Or period-specific text variants are needed

### Structural Validation
The decoder successfully:
- Mapped low numbers (≤335) to VDR words
- Mapped mid-range numbers to Declaration text
- Mapped high numbers (1400+) to Signers (e.g., cipher 1701 → "lewis")
- Confirmed the document stack structure

### Limitations
- Articles text is incomplete (only preamble ~50 words)
- Cipher 1 max value is 2906, but corpus only covers 2322 words
- Need full Articles (~3,535 words) to cover entire cipher range

## Technical Notes

- Text normalization: lowercase, alphanumeric only, whitespace split
- Offset formula: If N ≤ offset: idx = N-1, else: idx = (N - offset) + VDR_length - 1
- Window: ±10 words provides tolerance for edition variations
- All output is UTF-8 encoded
